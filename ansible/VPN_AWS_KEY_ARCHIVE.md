
# AWS 전용 WireGuard 키 보관 후보

- 기본 실행은 준비 안내만 출력한다.
- 실제 생성은 코드 검토·main 반영 후 별도 실행한다.
- 온프렘 키를 재사용하지 않고 Controller에서 AWS 전용 키를 생성한다.
- 기존 두 보관자의 age 공개키로 SOPS 암호화한다.
- 개인키 평문은 Python·SOPS 메모리와 표준입력에만 전달한다.
- Python 메모리의 확실한 소거는 보장하지 않는다.
- 주 보관자 복호화·원문 일치·공개키 대응 확인 후 암호문만 저장한다.
- 기존 보관본·연결 경로·부적절한 보관 폴더는 거부한다.
- 실패·취소 후 새 암호문이나 부분 파일이 남으면 자동 삭제·재생성하지 않는다.
- 새 모의시험 7개만 수행하며 기존 검사는 반복하지 않는다.

실제 AWS 서버 공급·예비 보관자 및 독립 사본 복구는 별도 작업이다.
AWS 개인키를 Terraform 입력·user_data·State·SSM 명령 인자·공개 로그에 넣지 않는다.
전달 S3에 평문 개인키를 올리지 않는다.
AWS 공급은 별도 비밀 전달·복구 경로를 확정한 후 진행한다.
