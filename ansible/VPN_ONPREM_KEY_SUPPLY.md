
# 기존 온프렘 키 공급 코드 후보

현재 단계는 코드 후보와 모의시험 준비다.
실제 키 복호화·서버 공급은 실행하지 않는다.

## 파일 역할

- vpn_onprem_key_supply.py: Controller에서 기존 암호문을 복호화하고 SSH로 공급하는 후보.
- vpn_key_install_remote.py: 서버 대상·서비스·키 대응·파일 보호 조건을 확인하는 후보.
- test_vpn_key_supply.py: 가짜 키와 임시 폴더를 사용하는 검사 10개.

## 확인할 동작

정상 공급, 기존 파일 보존, 키 짝 불일치 차단, 연결 파일 차단,
기록 실패 시 신규 파일 정리, 기존 폴더 권한 보존을 확인한다.

## 실제 적용 전 남은 조건

Controller Linux에서 10개 검사 통과와 코드 리뷰·병합이 필요하다.
실제 공급은 별도 실행 단계에서 대상·Source·서비스·파일 상태를 확인한 뒤 수행한다.
이 후보의 준비·시험 성공은 실제 공급 성공을 뜻하지 않는다.

개인키는 실제 실행 시 Controller 메모리와 SSH 암호화 채널을 거쳐
서버 메모리와 서버 보호 파일에 공급된다.
Python 메모리의 확실한 소거까지 보장하는 방식은 아니다.

SSH 결과 수신이 불확실하면 서버에 파일이 만들어졌을 수 있으므로
자동 재실행하지 않는다.

실패 과정에서 새로 만든 빈 보호 폴더는 남을 수 있다.
기존 폴더 권한을 자동으로 바꾸거나 서비스를 시작하지 않는다.

## 기록 경계

기존 키 생성·복구 검사와 기존 원복 모의시험 7개를 재실행하지 않는다.
새 키 공급 코드에 대한 별도 검사다.
