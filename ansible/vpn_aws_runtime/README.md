# AWS VPN 키 공급 실행 후보

작성자: 이유빈
작성일: 2026-10-20
관련 이슈: #16

## 범위
대상 확인, SSM 공개 프로그램 전달, 수신 세션 준비, 암호화 전달,
신규 키 설치와 임시 RSA 수신키 정리의 검토용 코드다.
기본 실행 허용은 차단하며 실제 실행에는 별도 입력과 승인이 필요하다.

## 확보한 근거
Controller에서 기존 개별 검사와 암호화·수신·설치 통합시험 5개 통과.
전달·수신 세션·키 공급 호출 지시서의 문법 검사 종료값 0.
이는 이전 보호 폴더에서 확보한 결과이며, Git 사본에서 다시 시험한 결과가 아니다.

## 남은 검증
새 호출 흐름의 실패·중단·정리 예약과 의존성 검사 및 팀 리뷰가 남아 있다.
실제 SSM, 운영 키 공급, AWS 설치본, 설정·전체 원복, VPN·RDS 통신은 미검증이다.
기존 통합시험 통과를 새 호출 흐름 전체의 통과로 확대하지 않는다.

## 자료 보관
운영 키·암호문·접속목록·승인 대상 파일·Plan·State·실행 로그는 포함하지 않는다.
함수와 playbook_dir의 상대 경로를 유지하기 위해 파일을 같은 폴더에 배치한다.
candidate-manifest.json은 이 Git 사본의 원문 대조용 목록이다.
실제 실행 승인이나 기존 보호 폴더의 후보 목록을 대체하지 않는다.
Git은 0600·0700 권한을 보존하지 않으므로 운영 실행 전에는
별도 보호 폴더에 해당 권한으로 배치하는 절차가 필요하다.
실제 생성에는 최신 NAT 활성 전체 입력으로 새 Foundation Plan을 검토한다.
이 PR은 V04~V08 완료나 AWS 실행 승인을 의미하지 않는다.
